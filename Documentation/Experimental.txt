# Script Editor
#-------------
- Code blocks style editor for EMEVD:
    - Split the file into Functions (group of Statements) and Statements (the individual commands/conditions)
    - Functions would use the Alias Editor style presentation (drag button + ID + EDD name) 
    - Statements would use the Alias Editor style presentation (drag button + command title -> right-click enum style selection to switch command), selection would populate property view.
